# 🌱 גדלים למחר – חבילת התחלה ל-Claude Code

## מה יש כאן
תיקייה זו היא נקודת ההתחלה לעבודה על הפרויקט מול Claude Code.

## איך מתחילים
1. קרא את `docs/claude-code-guide.docx` – המדריך המלא
2. העבר לכאן את כל קבצי ה-HTML שכבר נבנו (index.html, lessons/, teachers/, simulators/)
3. פתח טרמינל בתיקייה הזו והרץ: `claude`
4. אני אטען את CLAUDE.md אוטומטית ונתחיל לעבוד

## מבנה
- `CLAUDE.md` – זיכרון הפרויקט (קריטי - אל תמחק!)
- `.claude/` – סקילס, סאב-אייגנטס, פקודות סלאש, הוקס
- `docs/` – מדריך העבודה + מסמך החזון
- `lessons/`, `teachers/`, `simulators/` – תיקיות ריקות, מוכנות לקבצים שלך
