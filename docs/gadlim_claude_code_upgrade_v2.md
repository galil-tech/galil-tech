# גידול העתיד — קובץ תיקונים מלא לקלוד קוד
### שדרוג 17 הלומדות: ליבה משותפת · תאום · משחקיות · תיקונים כלליים ופרטניים

**מה זה:** קובץ הוראות יחיד לשדרוג כל הלומדות ודפי המרכז. מסודר ב-**3 פאזות עצמאיות**.
**איך לעבוד:** הרץ **פאזה אחת בכל פעם**, בדוק שהיא עובדת (כולל אחרי רענון דף), ורק אז המשך. **P1 חייבת לרוץ ולהיבדק ראשונה** — הכל נשען עליה.
**עקרונות קוד (חובה בכל שינוי):** קוד נקי ומתועד · `const`/`let` מסודר · פונקציות מופרדות · פתרונות פשוטים ויציבים · ביצועים טובים גם במכשירים חלשים · RTL מלא · הכל שורד רענון (localStorage).
**כלל-על אוטונומיה:** המטרה הסופית היא מערכת שתעלה לאינטרנט עם שרת (שלב 9). כל מבנה נתונים שנבנה עכשיו חייב להיות **תואם-שרת**: מפתחות עקביים, סכמה אחת, קריאה/כתיבה מרוכזת. שום רכיב לא הופך ל"מקור אמת מקומי" שיקשה על המעבר.
