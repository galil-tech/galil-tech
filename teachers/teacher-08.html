🧰 הכנה לפני השיעור

⛔ רק Thonny ו-MicroPython. לא להעלות לבקר קוד מ-Arduino IDE – זה מוחק את MicroPython ואת הדרייברים.

⚡ ציוד מעגל הבקרה (לקבוצה)

  • 📋 ESP32-S3 + חיישן לחות קרקע (AOUT→GPIO 6, VCC→3V3)
  • 📋 Servo כ"ברז" (אות→GPIO 15, אדום→5V, חום→GND)
  • 📋 זמזם פסיבי כ"הודעה" (S→GPIO 5, –→GND)
  • 📋 חוט מגע: כבל Jumper אחד ל-GPIO 4, שהקצה השני שלו חשוף או מודבק לנייר כסף
  • 📋 נורית ה-RGB המובנית בלוח (GPIO 48) – אין מה לחבר
  • ⚠️ הריצו את המעגל המלא (חיישן+בקר+ברז) על ערכה אחת לפני השיעור!
  • 🧰 ערכת חומרה רזרבית אחת לכל כיתה (ESP32/חיישן/Servo חלופיים) – למקרה תקלה, וגם לרמפת ההשלמה למעלה

🐍 קוד MicroPython (Thonny) – מלא, אפשר להעתיק כמו שהוא

# סגירת מעגל: חיישן → בקר → ברז + הודעה
import time
from machine import Pin, PWM
from soil_moisture_driver import SoilMoistureSensor
from touch_driver import TouchSensor
from ws2812_driver import WS2812LED
from buzzer_driver import PassiveBuzzer

soil = SoilMoistureSensor(pin_num=6)
touch = TouchSensor(pin_num=4)   # לא לגעת בזמן ההפעלה!
led = WS2812LED(pin_num=48, brightness=0.2)
buzzer = PassiveBuzzer(pin_num=5)
servo = PWM(Pin(15), freq=50)

def valve(angle):                # 0 = סגור, 90 = פתוח
    servo.duty_ns(500000 + angle * 2000000 // 180)

def wait_for_touch():
    while not touch.is_touched():
        time.sleep_ms(50)
    buzzer.alarm_beep(count=1, freq=1000, beep_ms=80)
    time.sleep_ms(500)

print("1. Sensor in AIR - touch the wire")
led.red()
wait_for_touch()
soil.calibrate_dry()
print("2. Sensor in WATER - touch the wire")
led.green()
wait_for_touch()
soil.calibrate_wet()

while True:
    moisture = soil.read_percent()
    print("Moisture:", moisture, "%")
    if moisture < 30:
        led.red()
        valve(90)
        buzzer.alarm_beep(count=3, freq=1000, beep_ms=100)
    elif moisture <= 60:
        led.yellow()
        valve(0)
    else:
        led.green()
        valve(0)
    time.sleep(1)

קבוצות

📋 משימות הקבוצה (זה הלב הטכני של השיעור!):

א. חיבור חיישן לחות קרקע ל-ESP32 (AOUT→GPIO 6, VCC→3V3)
ב. חיבור Servo (GPIO 15, 5V) + זמזם (GPIO 5) + חוט מגע (GPIO 4)
ג. המורה מריץ את קוד המעגל ב-Thonny – הקבוצה מכיילת במגע (אוויר → מים)
ד. הוכיחו שהמעגל סגור: שנו את ערך החיישן וצפו בברז/הודעה מגיבים אוטומטית
ה. דונו: איזו מערכת שלישית תרצו לחבר למעגל הזה?
ו. צילום המעגל השלם לקיר

🚨 בעיות נפוצות:

  • הברז/Servo לא מגיב: חשמל ה-Servo מפין 5V (לא 3V3), והאות ל-GPIO 15
  • הלוח מתאפס כשה-Servo זז: ה-Servo מושך זרם – כבל USB איכותי, או ספק 5V נפרד ל-Servo עם GND משותף ללוח
  • החיישן נותן ערך קבוע: ודאו שהוא נוגע בפועל במצע/במים
  • שני התנאים לא מתחלפים: הכיול התבלבל – הריצו שוב (F5): קודם אוויר, אחר כך מים. אחוז הלחות מודפס בחלון ה-Shell
  • המגע לא מגיב / מגיב לבד: נגעו בחוט בזמן ההפעלה – הריצו שוב בלי לגעת, ואז געו
  • ⚠️ בטיחות: שמרו על לוח ה-ESP32 עצמו יבש – רק קצה החיישן צריך לגעת במים/במצע הרטוב

🇮🇱 BioBee – רקע למורה

מי הם?

חברה ישראלית שנוסדה ב-1983 בקיבוץ שדה אליהו, בעמק המעיינות – 41 שנות פעילות ועדיין מובילים עולמיים בתחומם.

מה הם פותרים?

מגדלים חרקים מועילים (טורפים, צרעות פרזיטיות, אקריות טורפות, דבורי בומבוס) כתחליף להדברה כימית ולהאבקה ידנית – הדברה ביולוגית "ירוקה" במקום ריסוס רעלים.

מספרים לדיון:

  • 📅 41 שנות פעילות (מ-1983)
  • 🌍 פעילות ב-50+ מדינות, 6 חברות בת ו-5 אתרי ייצור
  • 🐝 מוצרים: טורפים, צרעות, אקריות, דבורי בומבוס

שאלות לדיון בכיתה:

  • "למה הדברה בחרקים טובים יותר מריסוס כימי?"
  • "מה הקשר בין BioBee לבין מעגל הבקרה שבנינו היום?" (שני המקרים – מערכת אחת פותרת בעיה במערכת אחרת, בלי התערבות ידנית מתמדת)
