עד אז – קוד המעגל הקיים (בלי מסך) ▾ 
import time
from machine import Pin, PWM
from soil_moisture_driver import SoilMoistureSensor
from touch_driver import TouchSensor
from ws2812_driver import WS2812LED
from buzzer_driver import PassiveBuzzer

soil = SoilMoistureSensor(pin_num=6)
touch = TouchSensor(pin_num=4)   # don't touch while starting!
led = WS2812LED(pin_num=48, brightness=0.2)
buzzer = PassiveBuzzer(pin_num=5)
servo = PWM(Pin(15), freq=50)

def valve(angle):                # 0 = closed, 90 = open
    servo.duty_ns(500000 + angle * 2000000 // 180)
valve(0)

def wait_for_touch():
    while touch.is_touched():
        time.sleep_ms(50)
    while not touch.is_touched():
        time.sleep_ms(50)
    buzzer.alarm_beep(count=1, freq=1000, beep_ms=80)
    while touch.is_touched():
        time.sleep_ms(50)
    time.sleep_ms(300)

print("1. Sensor in AIR - touch the wire")
led.red(); wait_for_touch(); soil.calibrate_dry()
print("2. Sensor in WATER - touch the wire")
led.green(); wait_for_touch(); soil.calibrate_wet()

last_alarm = 0
while True:
    moisture = soil.read_percent()
    print("Moisture:", moisture, "%")
    if moisture < 30:
        led.red()
        valve(90)
        if time.time() - last_alarm >= 3:
            buzzer.alarm_beep(count=3, freq=1000, beep_ms=100)
            last_alarm = time.time()
    elif moisture <= 60:
        led.yellow(); valve(0)
    else:
        led.green(); valve(0)
    time.sleep(1)

🔁 המעגל (בפתיחה)

מציירים על הלוח עיגול: חיישן ← מוח ← ברז ← מים ← אדמה ← חזרה לחיישן. "מה קורה אם חלק אחד נשבר?"

🎲 דואר החבילות (ליבה, 10 דק')

  1. כל צוות כותב פתק ("האדמה של TALI-BOT ב-23%") ושם במעטפה. על המעטפה: ממי · למי.
  2. את/ה = הראוטר: אוסף/ת ומחלק/ת לפי הכתובת.
  3. מעטפה בלי כתובת ← "לאן?" ← נשארת אצלך = הודעה שאבדה.
  4. מעבירים פתק פתוח מיד ליד ← כולם בדרך קראו ← למה צריך סיסמה והצפנה.

המונחים: כתובת = IP · "תשלח לי את הלחות" = בקשה · הפתק שחוזר = תשובה.

🔌 מעשי – צוותים

  • (8') חיווט: מהנדס/ת הזרימה – מסך: GND · VCC ← 5V · SDA ← 8 · SCL ← 9. חוקר/ת החושים – Servo: אות ← 15 · חשמל ← 5V · GND. המוח בודק · כרטיס טייס · את/ה מאשר/ת כל חוט 5V · USB.
  • (12') המעגל: כיול במגע (אוויר ← נגיעה, מים ← נגיעה) · שם הרובוט ואחוז הלחות במסך · אדמה יבשה ← אדום + צפצוף + ה-Servo "פותח ברז" ← משקים ← צהוב ← ירוק ← ה-Servo סוגר. הוכחנו: המעגל סגור.

🛫 כרטיס הטייס – הגרסה המלאה (+1)

  1. הכבל מנותק כשמחברים או מנתקים חוטים.
  2. חיישנים ל-3V3. רק המסך וה-Servo מקבלים 5V.
  3. אין חוט שמחבר ישר 3V3 ל-GND.
  4. חוקר/ת החושים בדק/ה כל חוט מול הכיתוב.
  5. זמזם: + ← GPIO 5 · חוט המגע רחוק מהלוח.
  6. מסך: SDA ← 8, SCL ← 9, חשמל ← 5V · Servo: אות ← 15, חשמל ← 5V · מים על מגש, 30 ס"מ מהלוח, בכפית.

🚨 בעיות נפוצות

ה-Servo מאפס את הלוחכבל USB איכותי, או ספק 5V נפרד ל-Servo עם GND משותף.
המסך דולק אבל ריקSDA ו-SCL הפוכים · כפתור הניגודיות בגב המסך.
אין זמן ל-Servo"ברז אנושי": הרובוט מזעיק ← תלמיד/ה משקה. Servo = בסיס, לא ליבה.
"עכשיו אין לי אינטרנט!"נכון – המחשב מחובר לרובוט, לא לאינטרנט. זה בדיוק השיעור: כל רשת היא חיבור למקום מסוים.
לא רואים את הרשת של הלוחהלוח לא הריץ את net_demo.py · להתקרב · לבדוק את השם.
ערכה של צוות התקלקלההצוות מקבל את ערכת המדריך/ה. את הדמו אפשר לעשות על ערכה של צוות שסיים.
