בסוף השיעור התלמיד...

ידע ומושגים

  • ✅ מסביר מהו חיישן ומה ההבדל בין סוגי חיישנים (טמפ', לחות, אור)
  • ✅ מסביר מהו ארדואינו ומה תפקידו כ"מוח" בין חיישן לפעולה
  • ✅ מבין את הלוגיקה הבסיסית של קוד: קרא → בדוק → פעל → חזור
  • ✅ יודע את טווחי הנוחות לטמפרטורה (15–28°C), לחות (50–80%), אור (400–1000 lux)
  • ✅ מכיר את Phytech – הדנדרומטר, חיסכון 500 מיליארד ליטר, שותפות עם Netafim

מיומנויות מעשיות

  • 🔧 מחבר חיישן טמפרטורה, לחות ואור לארדואינו לפי סכמה
  • 🔧 קורא ערכים ראשוניים ומפרש אותם (תקין / חריג)
  • 🔧 מסדר שורות קוד לסדר לוגי נכון
  • 🔧 מזהה תרחיש בעיה מתוך קריאת 3 ערכי חיישנים

חשיבה ביקורתית

  • 💭 מקשר בין ממצאי שיעור 5 (pH/EC) לצורך בניטור רציף
  • 💭 מנתח תרחיש: 3 ערכי חיישן → מזהה את הבעיה הספציפית
  • 💭 מסביר איך Phytech פותרת בעיה שהוא עצמו חווה בכיתה

גיימיפיקציה

  • 🌿 עד ~145 עלים לשיעור
  • 🌿 משלים לפחות 4 מתוך 6 משימות פרויקט

🧰 הכנה לפני השיעור – חשוב מאוד!

⚡ ארדואינו וחיישנים

  • 📋 ארדואינו Uno × מספר קבוצות
  • 📋 חיישן DHT22 (טמפ' + לחות) לכל קבוצה
  • 📋 חיישן BH1750 (אור) לכל קבוצה
  • 📋 כבלי חיבור (Jumper wires)
  • 📋 Breadboard לכל קבוצה
  • ⚠️ העלה קוד בדיקה לפחות יום לפני! אל תגלה ביום השיעור שמשהו לא עובד.

💻 קוד לארדואינו

// העתק לArduino IDE

#include "DHT.h"

#include <Wire.h>

#include <BH1750.h>

DHT dht(2, DHT22);

BH1750 lightMeter;

void setup() {'{'}

 Serial.begin(9600);

 dht.begin();

 lightMeter.begin();

{'}'}

void loop() {'{'}

 float t=dht.readTemperature();

 float h=dht.readHumidity();

 float l=lightMeter.readLightLevel();

 Serial.print("T:"); Serial.println(t);

 Serial.print("H:"); Serial.println(h);

 Serial.print("L:"); Serial.println(l);

 delay(2000);

{'}'}

ספריות: DHT sensor library + BH1750 by Christopher Laws

📐 סכמת חיבור

DHT22 (טמפ' + לחות):

VCC → 3.3V | GND → GND | DATA → Pin 2

BH1750 (אור):

VCC → 3.3V | GND → GND | SDA → A4 | SCL → A5

💡 הדפס סכמה ולמד אותה! תלמידים ישאלו שאלות בזמן חיבור.

🇮🇱 Phytech – רקע מלא למורה

מי הם?

חברת אגרוטק ישראלית שהוקמה בקיבוץ יד מרדכי. המוצר המרכזי: פלטפורמת PlantBeat שמנטרת בריאות צמחים בזמן אמת.

גיוס אחרון: $23.5 מיליון. שותפויות עם Netafim ו-Rivulis – שני ענקי ההשקיה העולמיים.

הדנדרומטר – מה זה?

חיישן שנצמד לגזע ומודד שינויים זעירים בקוטר. כשעץ "צמא" – הגזע מתכווץ. Phytech מגלים זאת לפני שהחקלאי רואה עלים צהובים.

מספרים לדיון:
