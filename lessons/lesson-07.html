מדריך חיבורים – לפני שנוגעים!

🌿 עד 15 עלים · קרא הכל לפני שמחברים

⚠️ 3 כללי זהב לפני חיבור ארדואינו:

1.תמיד נתק חשמל לפני שמחבר/מנתק כבלים. ארדואינו מחובר = לא נוגעים בפינים.
2.אסור לחבר 5V ישירות ל-GND. זה ישרוף את הארדואינו מיד. תמיד דרך נגד.
3.בדוק פעמיים לפני שמחבר חשמל. כבל אחד הפוך = חיישן מת.

💡 חיבור LED (נורית)

סכמת חיבור:

רגל ארוכה (+) של LED

→ נגד 220Ω → פין 9

רגל קצרה (–) של LED

→ GND (פין שחור)

⚡ למה נגד? LED ללא נגד = זרם גדול מדי = LED שרוף תוך שניות. הנגד מגביל את הזרם.

// הגדרה בקוד:

int ledPin = 9;

void setup() {'{'}

 pinMode(ledPin, OUTPUT);

{'}'}

// הדלקה:

digitalWrite(ledPin, HIGH);

// כיבוי:

digitalWrite(ledPin, LOW);

🔧 חיבור Servo (ברז אוטומטי)

בונוס!

3 כבלים בלבד – לפי צבע:

כבל אדום (VCC)

→ 5V

כבל חום/שחור (GND)

→ GND

כבל כתום/צהוב (Signal)

→ פין 6

✅ Servo בטוח! אין צורך בנגד. ה-Servo מגביל זרם לבד.

// קוד Servo:

#include <Servo.h>

Servo valve;

void setup() {'{'}

 valve.attach(6);

{'}'}

// פתיחת ברז:

valve.write(90);

// סגירה:

valve.write(0);

if / else – הארדואינו מחליט

🌿 עד 20 עלים

בשיעור 6 למדתם if. עכשיו מוסיפים else – "אחרת":

float ph = readSensor();

if (ph < 5.5) {'{'} // אם pH נמוך מדי

  digitalWrite(ledRed, HIGH); // נורה אדומה דולקת

  valve.write(90); // ברז נפתח

{'}'} else if (ph > 6.5) {'{'} // אם בסיסי מדי

  digitalWrite(ledRed, HIGH);

  valve.write(0); // ברז סגור

{'}'} else {'{'} // הכל תקין

  digitalWrite(ledRed, LOW); // נורה כבויה

  digitalWrite(ledGreen, HIGH); // נורה ירוקה

{'}'}
