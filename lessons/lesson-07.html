מדריך חיבורים – לפני שנוגעים!

🌿 עד 15 עלים · קרא הכל לפני שמחברים

⚠️ 3 כללי זהב לפני חיבור ה-ESP32:

1.תמיד נתק את כבל ה-USB לפני שמחבר/מנתק כבלים. ESP32 מחובר = לא נוגעים בפינים.
2.אסור לחבר 3V3/5V ישירות ל-GND, ואסור להכניס 5V לפין GPIO. ה-ESP32 עובד ב-3.3V – 5V ישרוף אותו. LED חיצוני – תמיד דרך נגד.
3.בדוק פעמיים לפני שמחבר חשמל. כבל אחד הפוך = חיישן מת.

🔔 חיבור זמזם + 💧 חיישן לחות

סכמת חיבור:

זמזם – רגל + (מדבקה קטנה, לא תמיד ברורה)

→ GPIO 5 (PWM)

זמזם – הרגל השנייה

→ GND · חיבור הפוך = צפצוף חלש יותר

חיישן לחות – AOUT (משיעור 6)

→ GPIO 6 · VCC → 3V3 · GND → GND

🌈 והנורית? נורית ה-RGB כבר מובנית בלוח (GPIO 48) – לא צריך לחבר אותה, ואין צורך בנגד. LED רגיל שמחברים בעצמכם – תמיד דרך נגד! 
# הגדרה בקוד (MicroPython):
from ws2812_driver import WS2812LED
from buzzer_driver import PassiveBuzzer
led = WS2812LED(pin_num=48, brightness=0.2)
buzzer = PassiveBuzzer(pin_num=5)

# הדלקה וצפצוף:
led.red()
buzzer.alarm_beep(count=3, freq=1000, beep_ms=100)
# כיבוי:
led.off()

🔧 חיבור Servo (ברז אוטומטי)

בונוס!

3 כבלים בלבד – לפי צבע:

כבל אדום (VCC)

→ 5V (פין 5V בלוח – לא לפין GPIO!)

כבל חום/שחור (GND)

→ GND

כבל כתום/צהוב (Signal)

→ GPIO 15

💡 לסרוו יש זרועות פלסטיק שמרכיבים על הציר (כולל בורג קטן). הרכיבו זרוע אחת – כך תנועת ה"ברז" ברורה ונראית לעין.
⚠️ ה-Servo מושך הרבה זרם: אדום רק לפין 5V של הלוח (לא דרך פס ה-breadboard), חום ל-GND – לא להפוך. אם הלוח מתאפס – נתקו USB וקראו למורה. 
# קוד Servo (MicroPython):
from machine import Pin, PWM
servo = PWM(Pin(15), freq=50)

def valve(angle):  # 0 = סגור, 90 = פתוח
    servo.duty_ns(500000 + angle * 2000000 // 180)

valve(0)   # מתחילים סגור

valve(90)  # פתיחת ברז
valve(0)   # סגירה

if / else – הבקר מחליט

🌿 עד 20 עלים

בשיעור 6 למדתם if. עכשיו מוסיפים elif ("ואם לא – אז אם...") ו-else – "אחרת". בפייתון אין סוגריים מסולסלים: ההזחה קובעת מה בתוך כל תנאי.

moisture = soil.read_percent()

if moisture < 30:        # אם האדמה יבשה מדי
    led.red()             # נורית אדומה
    valve(90)            # ברז נפתח
elif moisture > 80:      # אם רטובה מדי
    led.blue()
    valve(0)             # ברז סגור
else:                    # הכל תקין
    led.green()           # נורית ירוקה
